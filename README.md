# 🐍 100 Days of Python – 100 Projects Challenge

Welcome to my **#100DaysOfPython** journey!
This repository documents my commitment to building **100 Python projects in 100 days** to improve my programming skills, problem-solving ability, and consistency.

---

## 🚀 Challenge Goals

* 📅 Code **every day for 100 days**
* 🧠 Strengthen core Python concepts
* 🛠 Build real-world, hands-on projects
* 📈 Track progress and stay accountable
* 🌍 Share learning publicly

---

## 📌 Rules I Follow

* Code daily (no zero days)
* Each day = one project (small or big)
* Push code to GitHub every day
* Document what I learned
* Stay consistent over perfection

---

## 🗂 Project Structure

Each day has its own folder:

```
/Day01 - Project Name
/Day02 - Project Name
...
/Day100 - Project Name
```

Each folder may include:

* `main.py` – project code
* `README.md` – explanation (optional)
* assets (if needed)
